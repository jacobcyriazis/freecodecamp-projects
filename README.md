# freeCodeCamp Projects

These projects are the result of certification projects assigned by freeCodeCamp.org, and in most instances are not an accurate representation of my coding ability.

Due to the method of which these projects are tested, features I implemented through my own volition (such as more efficient methods of achieving the same goal, or SQL injection protection) were forced to be omitted to match the expected script and string outputs of the tests.
